# Home Assistant Add-on: Homepage
This is an unofficial Homepage add-on for Home Assistant, built on the official Homepage image (`ghcr.io/gethomepage/homepage`). A modern, fully static, fast, secure, fully proxied, highly customizable application dashboard with integrations for over 100 services and translations into multiple languages. Easily configured via YAML files.

Please visit the Homepage site for information about Homepage specifically: https://gethomepage.dev/
You can also check out their GitHub: https://github.com/gethomepage/homepage
